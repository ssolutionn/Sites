## Что закончено

Версия приложения — **0.9.0**, формат сохранения остаётся **1**. Девять внешних плагинов из сообщения владельца не установлены: в этой сессии их нет в каталоге установки. Локальные навыки из `.claude/skills/` доступны Codex через `.agents/skills/`; это отдельная вещь.

| Изменение | Где | Почему |
|---|---|---|
| Печать только перед сообщением, ответы игрока, реакция Верки на незагрузившееся фото | `st-phone.js`, `chatter.js`, `data.js` | Убрать вечное «печатает» и вернуть шутку именно в ЛС |
| Комментарии, собственный текст, быстрые ответы, двойной тап по фотографии | `ui/phone.js`, `theme.css` | Телефон должен отвлекать содержанием и позволять отвечать |
| Сохранение черновика, фокуса и курсора при обновлении | `ui/phone.js` | Приходящее сообщение не должно стирать написанное |
| Мытьё через `Scrubber`, несколько проходов туда-обратно | `st-home.js`, `campaign-view.js`, `campaign-ui.js` | Убрать поиск последних пикселей; назначение посуды и раковины сохранено |

| Предупреждения всех четырёх кастрюль, список блюд подноса, норма икры | `session.js`, `st-phone.js`, `st-tray.js` | Закрыть несогласованности после расширения плиты и рецептов |

## Проверки и повторение

Подробный результат, все замечания владельца и ограничения проверки: [docs/QA_v09.md](docs/QA_v09.md). Обзор кода: [docs/CODE_TOUR.md](docs/CODE_TOUR.md). Браузерные снимки: `production/qa/evidence/codex-v09/`.

Чекпоинт 0.9: **248/248 тестов**, обычная и нейтральная сборки, **58/58** отдельных браузерных проверок и **71/71** полный день 1 при 1280×720; ошибок консоли нет. Повтор при 1440×900 выполняется на замороженной сборке, отдельно от новых 3D-исходников.

```bash
npm ci
npm test
npm run build
npm run pacing
npm run preview -- --host 127.0.0.1 --port 4176 --strictPort
# В другом терминале; нужен установленный Playwright/Chromium:
PW=/path/to/playwright/index.mjs OUT=production/qa/evidence/codex-v09 node scripts/v09-shots.mjs http://localhost:4176/ all
PW=/path/to/playwright/index.mjs OUT=production/qa/evidence/codex-v09/day1 node scripts/campaign-e2e.mjs http://localhost:4176/ d1
VITE_NEUTRAL=1 npm run build -- --outDir dist-neutral
node scripts/check-neutral.mjs dist-neutral
```

В облаке используется системный Chromium через `/workspace/audit-sites/playwright-system.mjs`. Низкое качество задаётся **до загрузки** игры. `app.ui('quality')` посреди кухни открывает меню: это не способ настроить проверку. `placePot` теперь имеет аргументы `[burnerIndex, null, null]`; старые селекторы сценариев не подходят.

`v09-shots` использует фикстуры и перемотку для изолированных механик. `pacing-sim` — оценка всех семи дней через API, не живой плейтест. Полное мышиное прохождение дней 2–7, нативные Windows/macOS и Steam не объявлены проверенными. Скрипты теперь завершаются с ошибкой, если проверки провалились.

## Следующая работа: 3D

Владелец уточнил: **общий стиль мультяшный, продукты более реалистичные**, кухня уютная. Девушка и рыжий кот заданы в `references/02_character_and_title.jpg`; кухня и готовка — в `references/01_kitchen_and_gameplay.jpg`. Сохранить кудрявый пучок, красную повязку, светлый свитер, красный новогодний фартук. Изображения — направление, не готовый модельный лист.

Blender 4.3.2 доступен в облаке. Исходники новых моделей кладём в `assets/`, игровые GLB — по `docs/asset-contract.md`. Процедурные нарезанные кусочки остаются в игре: статической моделью нельзя заменить геометрию, создаваемую жестом ножа. Анимации существующих персонажей нельзя потерять при подмене модели.

Состояние 3D и команды воспроизведения дополняются после создания ассетов. Не запускайте одновременно два агента, меняющих одни и те же файлы в одном checkout; для независимой работы используйте отдельные ветки и папки.
