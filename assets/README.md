# Исходники уютного 3D-набора

27 моделей: 2 персонажа, 12 цельных продуктов, 8 предметов и 5 элементов кухни.
В каждой папке лежат редактируемый `.blend`, несжатый `.glb` и авторские PNG-текстуры.
Персонажи содержат риг, мимику и все клипы внутри одного GLB: 17 у героини, 10 у кота.
Материалы Principled, текстуры упакованы в Blender и GLB; внешних ссылок на текстуры нет.

Стиль задан владельцем: мультяшные персонажи и уютная кухня, более натуральная еда.
Ориентиры — `references/01_kitchen_and_gameplay.jpg` и `02_character_and_title.jpg`.
Меши, узоры одежды и текстуры продуктов созданы скриптами этого репозитория; сторонние
модели и сервисы Meshy/Tripo не использовались.

## Сборка

```bash
git lfs install
git lfs pull
npm ci
npm run models:sync     # проверка GLB, бюджеты, манифест, public-копия
npm run dev            # синхронизация выполняется автоматически
npm run build          # то же для веба и упаковки Electron
npm run models:preview # самостоятельный HTML в production/previews/
```

Изменять `public/assets/models/` вручную не нужно: это игнорируемая сгенерированная папка.
В `dist/` попадают только GLB и манифест; Blender-файлы и рабочие PNG остаются вне игры.
Статистика после проверки — `docs/cozy-model-stats.json`.

Для повторного создания моделей нужен Blender 4.3.2 с NumPy и Pillow:

```bash
npm run models:build
# Можно выбрать установленный Blender:
BLENDER_BIN=/path/to/blender npm run models:build
```

Генераторы в `scripts/art/`: `build_cozy_assets.py` (еда и реквизит),
`build_cozy_characters.py` (риг и клипы), `build_cozy_kitchen.py` (мебель).
`--root /path/to/output` позволяет получить отдельный набор для сравнения.
Для еды/реквизита доступен `--only food` или `--only props`.
Рендеры персонажей и продуктов воспроизводят соответствующие `render_*.py`.

`.blend` сохраняется до экспортной триангуляции. В GLB скин-меши выносятся в корни сцены,
а кости остаются под арматурой: это исправляет предупреждение glTF о родителях скин-мешей.
Клонировать персонажа нужно целой сценой через `SkeletonUtils.clone`, чтобы сохранить связи.
Поза сидящего кота запечена с опорой четырёх лап через Blender IK; решатель в игре не нужен.

## Что подключено

Игра загружает 12 ID: `girl`, `cat`, `knife`, `board`, `cat_bowl`, `back_counter`, `island`,
`fridge`, `egg`, `potato`, `potato_peeled`, `beet`. Цельные продукты используются в переноске
и охлаждении. Флаг `runtime` задаётся в `scripts/sync-models.mjs`.

Остальные 15 — кандидаты для дальнейшей замены, доступны в `model-gallery.html`.
Кастрюля, основная миска, раковина и плита пока сохраняют динамические процедурные части
и существующие ссылки анимации. Нарезанные куски всегда создаются жестом ножа.

Это рабочий арт-пилот: плечи и ворот героини, контакты рук с реквизитом, сон и ходьба кота
ещё требуют художественной доводки. Техническая проверка не заменяет оценку этих поз.
Результаты и ограничения — `docs/QA_models_v091.md`; контракт — `docs/asset-contract.md`.

## Git

`.blend`, `.glb` и PNG в `assets/` хранятся через LFS, правила — `.gitattributes`.
Обычный ZIP GitHub может содержать LFS-указатели; для разработки нужен `git lfs pull`.
