# Симулятор новогодней суеты — версия 0.5.0

Браузерная игра о подготовке к Новому году: семь игровых дней, десять блюд и общий праздничный стол.
Игрок управляет девушкой на кухне, режет продукты ножом на глаз, намазывает, наполняет, трёт,
собирает слои и шпажки, моет посуду, заказывает доставку и отбивается от кота.

Сборка выполнена по «ТЗ на новый билд игры Новогодняя суета» (версия задания 1.0, 7 октября 2026),
на основе тестовой версии 0.3.1. Это ТЗ лежит в `docs/TZ_Novogodnyaya_sueta_build_v04.md`.

## Что нового в 0.5

Суета стала настоящей: две конфорки и параллельная варка, остывание сваренного, соль и перец с пробой ложкой,
кот с голодом и миской, случайные пожелания гостей, бюджет и три способа доставки, грязная доска после сельди
и свёклы, темп, звёзды и медали, карточки заказов, всплывающие надписи и частицы, реплики гостей в финале,
испытание дня, скоростная нарезка и режим стрима с голосованием чата Twitch. Подробно — `CHANGELOG.md`.

## Запуск

Нужен **Node.js 20.19 или новее**.

```bash
npm ci
npm run dev        # откроет игру; адрес будет в терминале (обычно http://localhost:5173)
```

Готовая сборка лежит в `dist/`. Её нужно открывать через веб-сервер, а не двойным щелчком:

```bash
npm run build
npm run preview    # http://localhost:4173
```

Страницы:

- `index.html` — кампания (главное меню, журнал, практика);
- `classic.html` — исходный режим «Оливье за 5 минут» из 0.3.1;
- `gallery.html` — галерея девушки и кота с позами.

После `npm ci` игра работает без сети: нет сервера, аккаунтов и внешних API.

На Mac команды те же. Как открыть терминал в папке: Finder → правый клик по папке → «Новый терминал по адресу папки».

## Управление

| Ввод | Действие |
|---|---|
| Левый клик по полу | Идти в эту точку (без открытия панели) |
| Левый клик по станции или её метке | Подойти и открыть действие |
| Мышь у доски / клик по продукту | Положение ножа / один удар |
| <kbd>R</kbd> или «Повернуть» | Повернуть раскладку на 90° (кроме кружочков) |
| Удержание и движение мыши | Намазывание, перемешивание, тёрка, мытьё, уборка лужи, маринад |
| Перетаскивание | Шпажки канапе, фрукты, сервировка праздничного стола |
| <kbd>Q</kbd> или «📋 Рецепт» | Рецепты дня, шаги, пожелания гостей, вариант «без лука» |
| Миска: «🧂 Соль», «🌶 Перец», «👅 Попробовать» | Вкус перед перемешиванием; норма скрыта, проба отвечает честно |
| «🐾 Миска кота» | Покормить (сытый кот спит) или бросить мячик |
| <kbd>Esc</kbd> | Закрыть телефон или рецепт, иначе пауза |
| <kbd>M</kbd> | Звук вкл/выкл |
| «?» в HUD | Повторить подсказку для текущего места |

Все обязательные действия доступны мышью и экранными кнопками. При потере фокуса, скрытии вкладки
и отпускании кнопки вне окна удержание прекращается, а игра ставится на паузу без скачка времени.

## Кампания

| День | Название | Блюда | Новое |
|---|---|---|---|
| 1 | Начинаем подготовку | Оливье | Разрез кликом, поворот R, миска, перемешивание кругами, плита (картофель готов через 2:00), кот, радио |
| 2 | Ещё один салат | Крабовый салат | Мытьё миски, телефон, первый заказ (кукуруза) |
| 3 | Первые закуски | Бутерброды с икрой, фаршированные яйца | Намазывание, половинки и желтки, наполнение ложкой, заказ икры и разбор пакета |
| 4 | Мелкая работа | Тарталетки, фаршированные помидоры | Тёрка, крышечки и сердцевина, переполнение, просьба «без лука», заказ зелени |
| 5 | Слой за слоем | Селёдка под шубой | Тёрка, порядок слоёв, отмена последнего слоя, выкипание, гирлянда, заказ майонеза |
| 6 | Красиво разложить | Канапе, фруктовая тарелка | Кружочки, сборка шпажек, выкладка фруктов, кот опрокидывает компот, уборка лужи |
| 7 | Последние приготовления | Запечённая курица + финальная сервировка | Маринад кистью, духовка с окном и перегревом, расстановка 10 блюд на стол |

- День завершается только кнопкой «Завершить день», когда все блюда дня готовы. Таймера-проигрыша нет.
- После каждого блюда показываются оценка и 2–3 наблюдения, построенные по реально выполненным действиям.
- Блюдо появляется на праздничном столе. В финале камера показывает стол со всеми десятью блюдами.
- В журнале 7 карточек. Пройденный день можно переиграть, дальнейший прогресс при этом не стирается.
  Журнал хранит лучший и последний результат дня. Итог кампании — среднее лучших результатов семи дней.
- «Новая кампания» при существующем прогрессе требует подтверждения сброса.
- Если закрыть страницу посреди дня, при следующем запуске этот день начнётся заново, а прошлые результаты сохранятся.

### Оценка

Блюдо: `Q = 0.35·подготовка + 0.25·состав + 0.25·сборка + 0.15·пожелания`. Если характеристика неприменима,
её вес распределяется между остальными: бесплатных 100 баллов за несуществующее действие нет.

Блюдо (0.5): `Q = 0.30·подготовка + 0.20·состав + 0.20·сборка + 0.15·вкус + 0.15·пожелания` с тем же перераспределением.

День: `D = 0.75·среднее Q + 0.15·порядок + 0.10·темп` (темп 100 в пределах ориентира дня, к двойному — 40).
Звёзды: 55 / 75 / 90. Медали — за быстрый день, аккуратный нож, идеальный вкус, кота без добычи, сухой пол,
экономию и все пожелания. В 0.4 было `D = 0.85·среднее Q + 0.15·порядок`. Порядок начинается со 100. Штрафы: кража кота, выкипание,
оставленная лужа, непочиненные гирлянда или радио, немытая посуда к концу дня. Каждое происшествие штрафуется один раз.

### Нарезка

- Мышь двигает нож, клик сразу режет. Один удар проходит через все полоски под лезвием.
- Привязки к сетке и линий-подсказок нет; есть только кубик-образец.
- Клик по пустому углу рамки округлого ломтика — промах: продукт не тратится, анимации удара нет.
- Фигурные контуры: морковь, огурец, картофель, яйцо, лук. Колбаса, сыр, хлеб, сельдь и крабовые палочки —
  подготовленные бруски.
- Краевые обрезки не штрафуются в пределах допуска. По умолчанию допуск 10 % объёма порции. Для моркови и яйца,
  где эталонной сетки не хватает, допуск подобран эталонной нарезкой (`npm run calibrate`) и записан в данные продукта.
  Внутренние фрагменты обрезками не считаются: измельчение продукта в мелочь даёт низкую оценку.
- Кружочки для канапе — отдельный режим: продольный цилиндр, толщина определяется расстоянием между разрезами,
  поворот отключён с подсказкой.

### Другие ручные действия

- **Намазывание, маринад, слой шубы, мытьё, лужа** — маска покрытия. Видимый след и логика используют одну сетку,
  повторный проход больше 100 % не даёт.
- **Перемешивание** — считается угловой путь вокруг центра миски, нужно 4 оборота. Неподвижное удержание
  и рывки не засчитываются.
- **Тёрка** — засчитываются только полные движения вверх-вниз, 8 на порцию.
- **Наполнение** — ложкой: клик по рабочей тарелке набирает начинку, клик по корзинке/половинке/помидору кладёт её.
  Пустой ложкой можно снять переполнение.
- **Шпажки и фрукты** — перетаскивание. Подходящий слот принимает кусочек, иначе он возвращается на место.

### Продукты, посуда, доставка

- Продукты учитываются в игровых порциях. Порция резервируется при начале операции и списывается один раз
  при подтверждённом завершении. Отмена и смена вкладок продукт не тратят.
- Миска, поднос и форма становятся грязными после блюда. Мыть — у раковины.
- Телефон: «Сообщения», «Покупки» (чего не хватает для оставшихся шагов), «Заказ».
  Один активный заказ; статусы «принят → собирают → в пути → прибыл»; ожидание 45–75 с игрового времени.
  Можно ускорить кнопкой, если нечем заняться. Героиня уходит за кадр на 3 с и возвращается с пакетом.
  Продукты попадают в запасы только после раскладки по правильным местам (холодильник или кладовая).

## Конфигурация

- `src/campaign/data.js` — параметры кампании: время, окна помех, длительности, допуски, механики, веса оценки,
  продукты (порции, хранение, профиль нарезки, допуск обрезков), рецепты (шаги и зависимости), семь глав
  (блюда, запасы, грязная посуда, помехи, сообщения, просьбы).
- `src/campaign/layout.js` — раскладка кухни, станции, препятствия навигации, рабочие места подноса, места на столе.
- `src/config.js` — параметры режима «Оливье за 5 минут» (картофель на 2:00, раунд 300 с).

Режим разработчика `?dev` показывает FPS, вызовы отрисовки, число геометрий и текстур, а также кнопки
«Завершить день», «Кот», «Выкипание», «+30 с» и «Открыть все дни». `?seed=N` фиксирует случайность.
