# Новогодняя суета — тестовый прототип v0.3.1

Обновлённый исходный проект Claude: картофель готов на 2:00, добавлено радио с мелодией и ремонтом; новые 3D-персонажи, однокликовая нарезка, отдельная тренировка и галерея моделей. Основной игровой раунд пока остаётся прототипом «оливье за пять минут», а не полной игрой с семью днями и всеми блюдами.

## Быстрый запуск

В папке проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. В меню:

- **Тренировка нарезки** — морковь, огурец, яйцо, картофель и колбаса без таймера и помех.
- **Девушка и кот** — галерея: вращение камеры мышью, приближение колёсиком, переключение поз и выражения лица. Прямой адрес — `/gallery.html`.
- **Играть** — тестовый раунд на пять минут с плитой, котом, телефоном, гирляндой и радио. Картофель готов через две минуты после установки кастрюли.

Нужен Node.js, соответствующий полю `engines` в `package.json`. На Mac способ запуска тот же; на реальном Mac эта версия ещё не проверена. После установки зависимостей игра не обращается к внешним API.

## Новая нарезка

1. Выберите продукт.
2. Наведите мышь: нож перемещается по доске.
3. Кликните по продукту — сразу начинается разрез. Предварительно выбирать кусочек не нужно.
4. Режьте на полоски, нажмите **R** или **Повернуть**, затем режьте поперёк: один удар проходит через все полоски под лезвием.
5. Сравнивайте размер с образцом кубика. Зелёной линии и привязки к сетке нет: координату выбираете на глаз.

В тренировке видны аккуратность, число подходящих кусочков и сохранённая доля продукта. **Начать заново** сбрасывает текущий продукт, а нарезка остальных сохраняется. Есть кнопка возврата в меню.

В тренировке исходные ломтики имеют реальные выпуклые контуры. Геометрия режется по координате ножа, фрагменты сохраняют контур, площадь и толщину. Слишком тонкие части и превышение лимита отклоняются целиком: частичного разреза нескольких полосок не происходит.

Это нарезка заранее подготовленных ломтиков постоянной толщины. Произвольный угол лезвия, разрез целого овоща в любой плоскости, физика разлетающихся кусочков и разделение продукта по высоте пока не реализованы. В основном раунде сохранены прямоугольные порции исходного проекта; фигурные продукты доступны в тренировке.

## Персонажи

**Девушка:** объёмное лицо, глаза и ресницы, кудри и пучок, праздничная повязка, серьги, свитер с геометрическим узором, фартук с карманом и декоративным знаком «5», пальцы и обувь.

**Кот:** объёмная морда, зелёные глаза, уши, усы, белые лапы, полоски и изгибающийся хвост.

Оба персонажа уже заменены в основной сцене. Модели созданы геометрией и материалами Three.js, внешние растровые текстуры для них не нужны. Это стилизованная адаптация референса; качество исходной рекламной иллюстрации не воспроизведено один в один.

Отдельные файлы:

- `public/models/heroine.glb` — модель и клипы Idle, Walk, Mix.
- `public/models/cat.glb` — модель и клипы Idle, Walk, Reach.

GLB содержит иерархию частей с анимацией трансформаций, а не универсальный скелет с весами для ретаргетинга. Невидимый реквизит исключён из экспорта. Дополнительные позы и переключение эмоции реализованы в исходном JavaScript.

## Радио и ускоренная картошка

Тестовый раунд длится 300 секунд. Картофель готов на 120-й секунде, после сигнала остаётся около трёх минут. Выкипание кастрюли остаётся отдельной помехой.

Радио стоит слева на задней столешнице, доступно по метке «Радио». После начала раунда играет собственная негромкая синтезированная мелодия. На 85-й секунде включённое радио ломается: потрескивание, красный индикатор, уведомление. Подойдите и удерживайте «Поправить настройку» 2 секунды. Частичный ремонт сохраняется при уходе; после завершения музыка возвращается.

При исправном радио можно включать и выключать его кнопкой станции. M выключает весь звук. Добровольное выключение не даёт штрафа; непочиненная поломка — одна бытовая ошибка. На паузе, в меню и результате радио не играет.

Для быстрой проверки откройте `?dev`: доступны переход к 1:58 и кнопка «Сломать радио». Эти инструменты не требуются для обычного прохождения.

## Передача Claude

В полном пакете для Claude рядом с папкой проекта лежат `START_CLAUDE_v04.txt` и `TZ_Novogodnyaya_sueta_build_v04.md`. Передайте Claude весь ZIP и стартовую инструкцию. Версия 0.3.1 — тестовая основа, версия 0.4 с кампанией ещё предстоит по ТЗ. В архив входят исходники, тесты, экспортированные модели и готовая сборка `dist/`. Зависимости `node_modules` намеренно не включены.

Основные файлы:

| Файл | Назначение |
|---|---|
| `src/view/heroine.js`, `cat.js`, `model-utils.js` | Модели и позы персонажей |
| `src/gallery.js`, `gallery.html` | Просмотр моделей |
| `src/game/cutting.js` | Контуры, разрез, поворот и сохранение объёма |
| `src/game/game.js` | Однокликовый ввод `sliceBoard` и игровые действия |
| `src/view/board.js` | Геометрия еды, нож и крупный план |
| `src/main.js`, `src/ui/ui.js` | Тренировка и управление |
| `tests/cutting-v03.test.js` | Новые проверки нарезки |
| `scripts/export-models.mjs` | Повторный экспорт GLB и данных превью |

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Отчёт текущей версии — `docs/QA_v031.md`. GLB можно пересоздать командой `npm run export:models`; офлайн-превью — `python scripts/render-previews.py` после экспорта (нужны NumPy и Pillow).

Старый браузерный отчёт и старые скриншоты находятся в `docs/ОТЧЁТ_ПРОТОТИПА_v01.md` и `docs/screenshots/`. Они относятся к исходной версии, не подтверждают проверку v0.3.1. Скрипт `scripts/e2e.mjs` адаптирован к одному клику, но в этой работе не запускался. Новые радио и готовность 2:00 также включены в сценарий.

Сборка `dist/` предназначена для статического веб-сервера. Открытие HTML двойным кликом не заменяет запуск через сервер.

## Ограничения

Браузерная проверка кликов, производительность на слабых компьютерах, импорт GLB в Blender и работа Safari/Mac пока не подтверждены. Дальше нужен короткий живой просмотр галереи и тренировки, затем настройка камер и ощущений от ножа по результатам этого просмотра.

Семь игровых дней, дополнительные блюда, доставка, бабушка и кооператив в эту доработку не включены. Временный знак «5» из исходного прототипа сохраняется; он не является официальным бренд-ассетом.
