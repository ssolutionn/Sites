# Симулятор новогодней суеты — браузерный прототип

31 декабря, пять минут, один оливье. Игрок ставит картошку вариться, нарезает продукты
ножом с мышью, отбивается от кота, телефона, выкипающей кастрюли и погасшей гирлянды,
добавляет картошку последней и перемешивает салат.

Прототип сделан по «ТЗ на игру Новогодняя суета», версия 1.0 от 5 октября 2026 года.
Референсы из ТЗ лежат в `references/`.

## Запуск на Mac

Нужен **Node.js 20.19 или новее** (подойдёт LTS 22).

1. Установите Node.js: скачайте установщик LTS с nodejs.org или выполните `brew install node`.
2. Откройте Терминал в папке проекта и установите зависимости:
   ```bash
   npm install
   ```
3. Запустите игру:
   ```bash
   npm run dev
   ```
   Браузер откроется сам. Если нет — откройте адрес из терминала (обычно http://localhost:5173).

Игра работает без интернета после `npm install`: нет сервера, регистрации и внешних API.

### Сборка

```bash
npm run build     # готовые файлы появятся в dist/
npm run preview   # локальный просмотр собранной версии (http://localhost:4173)
```

Папку `dist/` можно выложить на любой статический хостинг. Если открыть `dist/index.html`
двойным щелчком (через `file://`), браузер заблокирует модули, поэтому используйте
`npm run preview` или любой локальный веб-сервер.

## Управление

| Где | Что сделать | Результат |
|---|---|---|
| Кухня | Клик по станции или её метке | Героиня идёт туда и открывает действие |
| Доска | Клик по невыбранному кусочку | Выбор кусочка (зелёная рамка) |
| Доска | Движение мыши | Где пройдёт нож |
| Доска | Клик по выбранному кусочку | Один разрез |
| Доска | «Повернуть» или <kbd>R</kbd> | Поворот продукта на 90° |
| Доска | Кнопки продуктов | Смена продукта, нарезка сохраняется |
| Доска | «В миску» | Перенос нарезанного продукта |
| Любая станция | «Назад» | Общий вид, время идёт |
| Миска | Удерживать «Перемешать» | 3 секунды, прогресс сохраняется |
| Гирлянда | Удерживать «Поправить контакт» | 2 секунды |
| Раунд | <kbd>Esc</kbd> или кнопка паузы | Пауза |
| Везде | <kbd>M</kbd> или кнопка динамика | Звук вкл/выкл |

Все действия доступны экранными кнопками, клавиатура не обязательна.
Потеря фокуса окна или скрытие вкладки ставит игру на паузу, а продолжить можно только кнопкой «Продолжить».

## Как устроена попытка

- Отсчёт 300 секунд начинается, только когда игрок нажмёт «Поставить картошку вариться» у плиты.
  До этого помех нет и время не идёт.
- Рекомендуемый порядок: морковь → колбаса → огурец → яйцо → горошек → майонез.
- На 270-й секунде (4:30) картошка готова, остаётся 00:30. Раньше достать её нельзя.
- Картошку можно перенести в миску только после остальных шести ингредиентов. Перемешивание
  доступно при полном составе, а завершённое перемешивание сразу даёт успех.
- Помехи: кот (35 с, затем каждые 35–50 с), телефон (55 и 165 с), выкипание (100 и 205 с), гирлянда (135 с).
  После 255 с новые помехи не начинаются.
- Оценка: `S = round(clamp(0.45·C + 0.40·A + 0.15·M − 4·E, 0, 100))`. Проверочные примеры из ТЗ (100 и 84) покрыты тестами.

## Конфигурация

Все числа баланса собраны в `src/config.js`:

| Параметр | Что задаёт |
|---|---|
| `roundDuration`, `potatoReadyAt` | 300 с и 270 с (зафиксированы ТЗ) |
| `noNewEventsAfter` | после этой секунды помехи не стартуют |
| `ingredients[].w/d` | размер ломтика в целевых кубиках (порция) |
| `targetSize`, `tolerance` | целевой кубик и допуск аккуратности 0,75–1,25 |
| `minCutFraction` | минимальная ширина отрезаемой части (0,2 кубика) |
| `maxPiecesPerIngredient` | лимит кусочков (150) |
| `knifeDuration`, `durations` | длительности ножа, действий и удержаний |
| `walkSpeed` | скорость героини |
| `events` | расписание и окна реакции для кота, телефона, кастрюли, гирлянды |
| `scoring` | веса, штраф за ошибку, пороги названий |

Раскладка кухни и точки станций — `src/game/layout.js`.

### Режим разработчика

Добавьте к адресу `?dev`, например `http://localhost:5173/?dev`. Появится панель:
переход к 4:28 (картошка), вызов кота, «готовы 6 ингредиентов», конец времени.
`?seed=123` фиксирует случайную последовательность (интервалы кота), например `?dev&seed=5`.

## Структура

```
src/
  config.js          баланс и расписание
  main.js            состояния приложения и главный цикл (единый источник времени)
  game/              логика без графики
    game.js          попытка: время, станции, действия, рецепт, помехи, результат
    cutting.js       геометрия нарезки, поворот, аккуратность
    scoring.js       оценка и названия
    layout.js        раскладка станций
    rng.js           фиксируемый генератор случайных чисел
  view/              Three.js
    scene.js         свет, камеры, переходы, реакции на события
    kitchen.js       кухня и реквизит
    heroine.js       героиня и её позы
    cat.js           кот
    board.js         доска крупным планом, нож, руки, миска
    textures.js      процедурные текстуры, загрузка логотипа
  ui/                интерфейс (DOM): HUD, панели, уведомления, телефон, экраны
  audio/sound.js     синтезированные звуки (WebAudio)
public/assets/logo-5.svg   логотип отдельным файлом — временная заглушка
tests/logic.test.js        автотесты логики (node:test)
scripts/                   сквозная проверка и скриншоты в браузере (Playwright)
```

Логика (`src/game`) не зависит от отображения: сцена и интерфейс только читают состояние
и вызывают действия, ничего не начисляя сами.

## Проверка

```bash
npm test
```

19 автотестов: объём при нарезке, отношение 1:2, отказ у края, лимит кусочков, поворот,
аккуратность, оценка (100 и 84), отметка 270 с при пропуске кадров, отсутствие помех после 255 с,
кража и замена, единственный исход у кота, выкипание и гирлянда, финал за 30 с, конец времени во время перемешивания, независимость перезапусков.

Сквозная проверка в браузере (нужен Playwright, в зависимости проекта он не входит):

```bash
npm run build && npm run preview          # в одном окне терминала
npx -y playwright@1.56.1 install chromium # один раз
PW=$(npm root -g)/playwright/index.mjs node scripts/e2e.mjs   # если Playwright установлен глобально
```

Результаты последней проверки — в `ОТЧЁТ_О_ПРОВЕРКЕ.md`.

## Внешние ресурсы и права

- **three.js 0.186.1** (MIT) и **Vite 8.3.2** (MIT) — версии зафиксированы в `package.json` и `package-lock.json`.
- Все модели, текстуры и звуки созданы в коде проекта: примитивы Three.js, рисунки на canvas, синтез WebAudio.
  Сторонних изображений, моделей, шрифтов и звуков нет.
- Иконки интерфейса — системные эмодзи, их вид зависит от ОС.
- `public/assets/logo-5.svg` — **временная заглушка** в стиле знака «5», нарисованная вручную. Перед показом
  замените её официальным исходником логотипа «Пятёрочки» с тем же именем файла: фартук, магнит,
  меню и вкладка браузера подхватят его автоматически.
- Профиль «Верка Отпускова» вымышлен. Фотографии нет: вместо неё показывается размытая заглушка, сетевых запросов нет.
