# Навыки Codex для игры

В `.agents/skills/` подключены восемь существующих пакетов из `.claude/skills/`.
Ссылки используют исходные инструкции и дополнительные файлы, поэтому Claude и Codex читают одну версию правил.

| Навык | Применение |
|---|---|
| `three-best-practices` | Геометрия, материалы, текстуры, память и производительность Three.js |
| `game-feel` | Жесты мышью, допуски, звук и видимый результат кухонных действий |
| `game-ui-ux` | Читаемость интерфейса, навигация и управление |
| `balance-check` | Темп, экономика, оценки и сложность |
| `recipe-design` | Рецепты и согласованность их игровых шагов |
| `code-review` | Проверка изменений и регрессий |
| `browser-visual-qa` | Проверка мышью в Chromium, снимки и ошибки консоли |
| `release-checklist` | Проверки перед выпуском |

Это локальные навыки проекта. Плагины Go: Production Engineering, Codex Dev Workflows,
Meshy, Build 3D Game Rooms, Development OS, Game Development Studio, Tripo 3D,
Game Studio и Unity Essentials через эти ссылки не устанавливаются.
Их инструменты и облачные сервисы появятся только после установки соответствующих плагинов в клиенте Codex.
Для этой игры основной стек — JavaScript, Three.js, Vite и Electron; переход на Go или Unity не требуется.

После установки и появления инструментов Meshy/Tripo в сеансе можно будет создавать модели из
описаний и референсов через эти сервисы. Плагины для игровых комнат и студии могут добавить
свои процессы сборки сцен и проверки. Это нужно проверять по фактически доступным инструментам:
название плагина само по себе не гарантирует риг, анимацию или пригодность модели для игры.
Blender 4.3.2 уже установлен в среде и доступен для создания, экспорта и проверки собственных моделей.
