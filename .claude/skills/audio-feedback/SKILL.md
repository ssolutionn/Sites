# Звуковая обратная связь кухни

## Как устроено сейчас (src/audio/sound.js, src/main.js)

1. Класс `Sound` синтезирует всё через WebAudio (`_tone` — осциллятор, `_noise` — фильтрованный шум); файлов нет. `AudioContext` создаётся в `unlock()` по первому действию игрока.
2. `sound.play(name)` — `switch` примерно на 35 имён (`chop, deny, boil, meow, hiss, purr, phone, ready, success, fail, grate, salt, pour, fizz, cash, bag, click…`); молчит, если звук выключен или контекст не запущен.
3. События игры → звуки: таблица `SOUND_OF` в `src/main.js`, функция `dispatch()`; `actionStart` играет `work` (кроме ножа, щепоток и т. п.); отказ команды из `DENY` и неверный росчерк ножа — `deny`.
4. Радио — `sound.syncRadio(playing, clock)` каждый кадр: 16 нот по 0,30 с от игрового `clock`, глохнет при поломке, выключении и паузе; поломка — `radioBroken`.
5. Общая громкость — `master` 0,5, `setMuted()` хранится в `localStorage['olivie.muted']`; шин, ограничения повторов и вариаций высоты нет (кроме случайных нот `boil`).

## Список звуков кухни

| Событие (видимая причина) | Звук | Сейчас |
|---|---|---|
| Радио играет | фоновая мелодия, лёгкая «радийная» полоса | `syncRadio` |
| Радио ломается | треск + срыв тона, потом шипение до ремонта | `radioBroken` (без шипения) |
| Нож: морковь, огурец | хрусткий короткий удар, яркий шум 3–5 кГц | `chop` (один на все) |
| Нож: яйцо, картофель | мягкий глухой удар, шум ниже 1,5 кГц, без щелчка | нет |
| Нож: колбаса, сыр | плотный удар средней яркости | нет |
| Нож скользит по доске (росчерк) | тихий шорох, громкость от скорости мыши | нет |
| Кастрюля поставлена | стук металла о конфорку | `added` |
| Кипение, первая минута | редкие пузыри | нет |
| Кипение, вторая минута | частое бульканье, растёт к готовности | `boil` — разовый сигнал |
| Вода убегает | шипение на конфорке, тревожнее кипения | `boil` |
| Перемешивание | влажный «хлюп» на каждую четверть оборота | нет |
| Холодильник открыт | щелчок уплотнителя + гул, пока открыт | нет |
| Сообщение в телефоне | короткое уведомление | `phone` |
| Звонок телефона | повторяющийся рингтон до ответа | нет |
| Курьер у двери | дверной звонок «динь-дон» | нет (`bag` — шорох пакета) |
| Кот просит еду / сыт / ворует | мяу / мурчание / шипение | `meow`, `purr`, `hiss` |
| Блюдо готово, день готов | короткий стингер успеха | `success`, `ready` |
| Ошибка игрока | мягкий отказ, не громче удара ножа | `deny` |

## Уровни микса (ориентиры, сверять на слух в наушниках и динамиках ноутбука)

- Музыка (радио): около −18 LUFS кратковременной громкости; при тревоге и стингере — приглушить на 4–6 дБ на 1–2 с.
- Окружение (кипение, гул холодильника): на 6 дБ тише музыки, около −24 LUFS.
- Действия игрока (нож, ложка, губка): пики −10…−6 dBFS — самый заметный слой.
- Тревоги (убегает вода, кот ворует, звонок, курьер): пики −8…−6 dBFS, слышны поверх всего.
- Интерфейс (клики, `deny`): −16…−12 dBFS, никогда не громче ножа.
- Общий пик не выше −1 dBTP; громкость выключенного звука — 0, а не «почти 0».

Приоритет при наложении (выше — важнее, младшие приглушаются): 1) тревоги;
2) действие игрока прямо сейчас; 3) стингеры успеха/ошибки; 4) окружение; 5) музыка.
Одновременно не больше 8 голосов; при переполнении гасить самый тихий младшего приоритета.

## Правила

- Нет звука без видимой причины: каждый звук отвечает событию, которое игрок видит в кадре или в HUD (нож ударил, пузыри пошли, кот в кадре).
- Ограничение повторов: один и тот же звук не чаще раза в 60–80 мс (нож, щепотки, тёрка), уведомления — не чаще раза в 2 с; повтор в окне — пропуск, не очередь.
- Вариации: высота ±3–6 % и громкость ±2 дБ на каждое воспроизведение ножа, пузырей, шагов; без вариаций повтор звучит как «пулемёт».
- Звук продукта выбирается по продукту на доске, а не по кнопке: таблица продукт → профиль (хрусткий, мягкий, плотный) в данных, не в коде.
- Пауза и потеря фокуса глушат всё, кроме интерфейса паузы; радио продолжается с той же ноты.
- Новый звук добавляется в два места: имя в `Sound.play` и строка в `SOUND_OF` (или явный вызов рядом с событием) — и строкой в таблицу выше.
- Если появятся файлы: Ogg/Opus 48 кГц, до 100 КБ на эффект, загрузка после `unlock()`, без блокировки первого кадра.

## Проверка

1. `npm test` — логика не сломана (звук в тестах не участвует).
2. В браузере с `?seed=3`: пройти день 1, на каждое действие из таблицы — звук есть и совпадает с картинкой по времени (≤ 50 мс на слух).
3. 20 быстрых росчерков подряд — без треска и перегруза, звуки не накапливаются.
4. Кнопка «Звук» и клавиша M: полная тишина и возврат с той же громкостью после перезагрузки.
5. Итог — словами в отчёте: что проверено, что не проверено и почему (браузер без звукового устройства — `NOT ASSESSED`, а не «звук в порядке»).
