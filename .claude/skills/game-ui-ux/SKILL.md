# Game UI/UX — новогодняя кухня

Источник правды — `design/ui/ui-guidelines.md`, токены — `src/ui/theme.css`. Этот навык — короткий
порядок работы, чтобы интерфейс не скатился обратно в «набор функциональных панелей».

## Перед тем как писать разметку

1. Определи слой: **над сценой** → `.glass` (тёмное стекло); **отдельный экран** → бумага
   (`.card.dialog` внутри `#overlay`). Третьего стиля нет.
2. Определи иерархию: что игрок делает **сейчас** (одна фраза), какой **таймер** важен, какой
   **предмет** активен, где **отклик**. Всё, что не отвечает на эти четыре вопроса, — не на экран,
   а в книгу рецептов, телефон или «?».
3. Одна главная кнопка (`primary`). Срочное — `danger`. Обучение — `gold`.

## Обязательные правила

- Только токены из `theme.css` (`--pine`, `--berry`, `--gold`, `--paper`, `--glass`, `--on-glass`,
  радиусы `--r-*`, отступы `--sp-*`). Новые hex-цвета в разметке запрещены.
- Шрифт Nunito, минимум 12.5 px; цифры времени — `tabular-nums`.
- Док станции: `←` (класс `dock-back`), фишки (`prod-chip`), главная кнопка справа, строка отклика
  `data-live`. Инструкции в доке не пишем: для этого `tip()` (один раз) и `s.setHint()` (причина отказа).
- Метки станций — только значок, подпись по наведению.
- Уведомления — компактные, ≤ 3, у срочных красная кромка и таймер.
- Телефон — цельное устройство с домашним экраном и приложениями, а не вкладки.
- Никаких технических панелей без `?dev`; никаких английских подписей; никаких ссылок на тестовые страницы.
- UI не меняет состояние игры напрямую — только через `act(...)` (команды сессии).
- Обновляй DOM только при изменении (`_set(id, html)` или сигнатура панели `_sig`), не каждый кадр.
- Перерисовка не должна ломать фокус и нажатие: кнопки внутри часто меняющихся блоков — через `data-live`.

## Проверка (обязательно после изменения)

1. `npx vite build` без ошибок.
2. `npx vite preview --port 4173` и
   `PW=/opt/node-tools/node_modules/playwright/index.mjs node scripts/ui-shots.mjs http://localhost:4173/ 1280x720`
   и то же для `1440x900`.
3. Посмотри снимки `production/qa/evidence/ui_*.png`: ничего не перекрывает продукт и руку с ножом,
   нет переносов в заголовках стекла, нет двух главных кнопок, нет `#dev`.
4. Пройди сценарий мышью (`scripts/board-shots.mjs` для доски). Скриншоты сохраняются как доказательство.

## Частые ошибки

- Светлая карточка поверх яркой сцены — «сайт». Нужна `.glass`.
- Текст-инструкция в каждой панели — перегруз. Убрать в совет.
- Кнопка, которая выглядит нажимаемой, но выключена без причины — добавь `title` и строку отклика.
- Всплывашка по центру поверх доски в крупном плане — совет должен уходить влево (`#tip.side`).
