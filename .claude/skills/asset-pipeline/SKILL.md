# Конвейер 3D-ассетов

Источники истины: `docs/asset-contract.md` (как устроен файл) и `design/art/art-bible.md`
(как выглядит). Этот скилл — сжатый порядок действий. Если он расходится с контрактом, прав контракт.

## Когда применять

- Художник прислал или обновил `.blend` / `.glb` (героиня, кот, мебель, реквизит, цельные продукты).
- Процедурный объект из `src/view/*` заменяется моделью (порядок — арт-библия, раздел 9).
- Ревью модели или загрузчика.

Не применять к кускам на доске (`cutboard.js`), крошкам, частицам, пару, кольцам станций — они
процедурные навсегда.

## Шаг 1. Файл на своём месте

- [ ] Исходник и экспорт лежат рядом: `assets/<категория>/<asset>.blend` и `<asset>.glb`
      (категории: `characters/girl`, `characters/cat`, `food`, `kitchen`, `props`).
- [ ] Имена `snake_case`, ASCII, без точек и пробелов; клипы — `<asset>_<clip>.glb`.
- [ ] Корневой узел с префиксом: `char_`, `kit_`, `prop_`, `food_`.
- [ ] Моменты клипов (касание, удар) — в `<asset>.clips.json`.

## Шаг 2. Геометрия и оси

- [ ] 1 единица = 1 м; экспорт с +Y Up; корень и арматура: location 0, rotation 0, scale 1; без отрицательного scale.
- [ ] Смотрит в +Z glTF (в Blender — в камеру в виде Front, по −Y).
- [ ] Pivot по классу: персонажи — между стоп на полу; реквизит — центр дна; мебель — центр
      основания; двери — на петле; нож — на кромке, остриё в −Z; у ручного реквизита есть узел `grip`.
- [ ] Игровые размеры совпадают с арт-библией, раздел 5 (верх острова 0.90, доска 0.60 × 0.40 × 0.03 …).
- [ ] Подвижные части — отдельные узлы с договорными именами (`lid`, `door`, `screen`, `led`, `bulb_NN`).

## Шаг 3. Материалы и бюджеты

- [ ] Только Principled BSDF; Base Color и Emission — sRGB; ORM и Normal — Non-Color; normal — OpenGL.
- [ ] Цвета из палитры арт-библии; без `#ffffff` и `#000000` в альбедо; логотип — `m_brand_logo`.
- [ ] Текстуры не больше 2048 (персонажи) / 1024 (мебель, главный реквизит) / 512 (мелочь); стороны — степени двойки.
- [ ] Без transmission; Alpha Blend — только стекло.
- [ ] Треугольники, материалы, кости — в пределах таблицы контракта, раздел 6.
- [ ] Скиннинг: не больше 4 влияний; кости ≤ 60 (героиня) / ≤ 40 (кот); только деформирующие.
- [ ] GLB без сжатия (Draco, meshopt и KTX2 в игре пока не подключены — сжатый файл не загрузится).

## Шаг 4. Автоматическая проверка

```
npx @gltf-transform/cli validate assets/<путь>/<asset>.glb   # ноль ошибок
npx @gltf-transform/cli inspect  assets/<путь>/<asset>.glb   # сверить с бюджетом
```

Потом — three.js editor (https://threejs.org/editor/): модель стоит, смотрит в +Z, клипы играют.

## Шаг 5. В игру

- [ ] `npm run models:sync` копирует `.glb` в `public/assets/models/` и обновляет `manifest.json`.
      Если скрипта ещё нет — копирование и запись в манифест вручную, и это отмечается в отчёте.
- [ ] Загрузка через `src/view/assets.js` при запуске, до первого кадра. Во время игры не подменять.
- [ ] Запасной вариант жив: без файла или при ошибке работает процедурный конструктор. Проверить
      оба режима (с GLB и с `?procedural=1`).
- [ ] В сцене одна героиня и один кот — GLB либо процедурная модель, не обе.
- [ ] Код двигает подвижные части относительно позиции покоя из GLB, а не по жёстким числам.
- [ ] Тени: меши — `castShadow` и `receiveShadow`, пол и стены — только `receiveShadow`.
- [ ] Металл художника требует env map (RoomEnvironment + PMREM) — без неё сталь чёрная.

## Шаг 6. Доказательство

- [ ] Скриншоты в общем и в крупном плане при игровом свете:
      `production/qa/evidence/model_<asset>_<ГГГГ-ММ-ДД>_<вид>.png`. Без скриншота модель не принята.
- [ ] Тот же кадр с `?procedural=1` — для сравнения масштаба и цвета.

## Отчёт

Первой строкой — вердикт, одно слово из списка (по убыванию серьёзности):
`НЕ ГОТОВО` (нарушение контракта) › `ЗАМЕЧАНИЯ` (принять можно, есть что поправить) ›
`НЕ ОЦЕНЕНО` (часть проверок не выполнена) › `ГОТОВО` (всё проверено и в порядке).

Дальше — по одной строке на каждый шаг 1–6: `ПРОВЕРЕНО`, `НАРУШЕНИЕ: <что>` или
`НЕ ПРОВЕРЕНО: <шаг> — <почему>` (нет файла, нет скрипта, не удалось запустить браузер).
Невыполненный шаг не может дать вердикт `ГОТОВО`. Найденное нарушение не прячется за `НЕ ОЦЕНЕНО`.

## Частые ошибки

| Симптом | Причина | Исправление |
|---|---|---|
| Модель лежит на спине | экспорт без +Y Up | включить +Y Up |
| Стоит спиной к камере | в Blender смотрела по +Y | развернуть, чтобы смотрела по −Y (в виде Front) |
| В 100 раз больше или меньше | сантиметры или не применён scale | Unit Scale 1.0, Apply All Transforms |
| Сталь чёрная | metalness 1 без env map | подключить env map; до этого metalness ≤ 0.6 |
| Анимация не находит кости | точки или пробелы в именах | переименовать в `snake_case` |
| Файл не грузится | GLB сжат Draco или meshopt | экспорт без сжатия |
| Цвета блеклые или кислотные | ORM/Normal помечены как sRGB или наоборот | Non-Color для данных, sRGB для цвета |
| Рвётся кожа на сгибах | больше 4 влияний | Limit Total = 4, нормализовать веса |
