# Отчёт о проверке прототипа

Дата: 5 октября 2026 года.

## В какой среде проверял

| Что | Значение |
|---|---|
| ОС | Linux (облачный контейнер), **не macOS** |
| Браузер | Chromium 141 (Playwright 1.56.1), без интерфейса (headless) |
| Графика | SwiftShader — программный рендер без видеокарты |
| Node.js | 22.22.0 |
| Разрешения | 1280 × 720, 1920 × 1080, изменение окна 1280 × 720 → 960 × 760 |

**На Mac проверку не запускал.** Chrome, Safari и Firefox на macOS в этой среде недоступны.
Производительность на реальной видеокарте не измерял. В SwiftShader без GPU получилось 1–3 кадра/с,
и для Mac это значение ничего не говорит. Перед показом стоит один раз пройти игру на целевом Mac
в Chrome и Safari.

## Что запускалось

1. `npm test` — 19 автотестов логики, **19 из 19 прошли**.
2. `npm run build` — сборка без ошибок (`dist/`, JS ≈ 655 КБ, gzip ≈ 172 КБ).
3. `scripts/e2e.mjs` — сквозной сценарий в браузере: настоящие клики мышью по меткам станций,
   по доске (нарезка ножом), по уведомлениям и кнопкам, удержание кнопок, клавиши `R` и `Esc`.
   **22 из 22 проверок прошли** и в 1280 × 720, и в 1920 × 1080.
4. Скриншоты каждого этапа (выборка в `docs/screenshots/`).

Медленный рендер не исказил игровую логику: ожидания в сценарии привязаны к состоянию игры,
а не к реальному времени.

| № | Критерий | Как проверено | Итог |
|---|---|---|---|

| 12 | Выкипание останавливается; пропуск = одна ошибка без задержки картофеля; гирлянда чинится | тест + e2e | ✅ |
| 13 | После 270 с нет срочных помех; финал укладывается в 30 с | тест (все старты помех ≤ 255 с) + e2e (финал за 11,7–13,2 с игрового времени) | ✅ |

| 16 | Пять перезапусков без лишних событий, старых кусочков и ускорения | e2e (5 перезапусков) + тест (одинаковый сид → одинаковое расписание) | ✅ |
| 17 | Интерфейс читаем на целевых разрешениях, звук отключается, ошибки объясняются | скриншоты 1280 × 720, 1920 × 1080, 960 × 760 | ✅ визуально; звук на слух не проверял (в headless нет вывода звука) |

Дополнительно проверено: конец времени во время удержания «Перемешать» даёт поражение (отдельный тест),
смена станции во время движения ножа отменяет разрез и сохраняет продукт (тест).
Пауза во время перехода камеры, ремонта и телефона работает по тому же пути (время и анимации
идут только от главного цикла), но отдельные сценарии для каждого случая в браузере не прогонял.

## Отклонения от референсов

- Героиня и кот собраны из примитивов Three.js (сферы, цилиндры, конусы) и процедурных текстур.
  Признаки из ТЗ сохранены: каштановые кудри, красная повязка со снежинками, красно-белый свитер,
  красный фартук с белой «5», рыжий полосатый кот с узнаваемой мордой и хвостом. Но лица проще и
  менее выразительны, чем на иллюстрациях из презентации.
- Логотип «5» — **самодельная заглушка** (`public/assets/logo-5.svg`), а не официальный знак.
- Титульный экран — HTML-карточка поверх 3D-сцены с героиней и котом, без иллюстрации из презентации.
- Кухня упрощена: меньше декора, нет верхних шкафов, фасады однотонные с текстурой дерева.
- Шрифт системный, фирменного шрифта нет.
- В интерфейсе используются системные эмодзи: на macOS они есть, в Linux-среде проверки часть не отрисовалась.
- Крупный план доски показан со стороны игрока: героиню в этот момент скрываем, в кадре только её руки, нож и продукт.

## Что не доделано или упрощено

- Нет проверки на Mac (Chrome, Safari, Firefox) и нет замеров производительности на реальном GPU.
- Звуки — временные синтезированные эффекты, музыки нет (в ТЗ она необязательна).
- Кража кота с доски в крупном плане не анимирована лапой: кусок исчезает, появляются уведомление и кнопка «Взять замену».
- Маршруты героини — прямые отрезки по свободной зоне без обхода препятствий (по ТЗ этого достаточно).
- Баланс (порции, интервалы, длительности) — стартовый: игровых тестов с людьми не было.
