Перед тобой исходный проект «Новогодняя суета», обновлённая версия 0.3.0.

Сначала распакуй архив, изучи README.md и docs/QA_v03.md, установи зависимости npm ci, выполни npm test и npm run build. Открой игру через npm run dev. Проверь галерею gallery.html и кнопку «Тренировка нарезки» в главном меню.

Не заменяй эти модели упрощёнными примитивами. Девушка и кот уже встроены в сцену, их реализация находится в src/view/heroine.js, src/view/cat.js и src/view/model-utils.js. Отдельные GLB находятся в public/models/. Модели не используют растровые текстуры, анимация в GLB выполнена по иерархии частей. Дополнительные игровые позы и эмоции находятся в JavaScript.

Нарезка: canvas вызывает Game.sliceBoard, один клик — один удар без предварительного выбора части. cutAcross режет все полоски под лезвием. Положение разреза свободное по X, без сетки и нарисованной направляющей. R поворачивает всю раскладку на 90 градусов. В тренировке продукты имеют выпуклые контуры, которые реально разделяются геометрически. Не заменяй эту механику на заранее подготовленные кубики или кнопочное заполнение прогресса.

Перед изменениями проверь поведение в настоящем браузере: загрузка галереи, все позы, выбор каждого продукта, разрез мышью, поворот, поперечный разрез сразу нескольких полосок, отказ у края, сброс продукта, возврат в меню, запуск обычного раунда. Сообщай наблюдённые ошибки, не выдавай старые скриншоты за новую проверку. 28 логических тестов не заменяют проверку интерфейса.

Дорабатывай этот проект последовательно. Сначала качество и удобство моделей/нарезки, затем по отдельному согласованию сценарий семи дней и новые блюда. Реализация сейчас режет подготовленные ломтики постоянной толщины, а не произвольные 3D-объекты по любой плоскости.
