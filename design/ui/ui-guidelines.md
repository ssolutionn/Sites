# Интерфейс «Симулятора новогодней суеты» — правила

Версия 0.6 (2026-10-08). Код: `src/ui/theme.css` (токены и компоненты), `src/ui/campaign-ui.js` (разметка).
Навык для агентов: `.claude/skills/game-ui-ux/SKILL.md`.

## 1. Идея

Игра — это кухня, а не сайт. Интерфейс тихий, тёплый и праздничный, а главное на экране — 3D-сцена и руки.

- **Над сценой — тёмное стекло** (`.glass`): HUD, док станции, уведомления, советы. Сцена яркая,
  поэтому тёмный полупрозрачный слой читается на любом фоне и не спорит с продуктами.
- **Экраны вне кухни — тёплая бумага**: меню-диалоги, интро дня, итоги, пауза, книга рецептов.
  Это «страницы» поучительной книги.
- **Одна задача — одна точка внимания.** Всегда видно: что делать сейчас → сколько времени →
  что варится или горячее → что случилось (отклик). Всё остальное — по запросу.

## 2. Палитра

| Токен | Цвет | Где |
|---|---|---|
| `--pine` / `--pine-hi` | #1f5c46 / #2c8a5f | главное действие, прогресс, «готово» |
| `--berry` / `--berry-dark` | #d23c3c / #a32a2f | срочно, ошибка, кот у колбасы |
| `--gold` | #f2b544 | заголовки стекла, текущий шаг, акцент, фокус |
| `--paper` / `--paper-2` / `--paper-line` | #fff8ec / #f6ead4 / #e6d6b8 | бумажные экраны |
| `--ink` / `--ink-2` | #2b221c / #6e5e50 | текст на бумаге |
| `--glass` / `--glass-strong` | rgba(26,21,18,.66 / .82) | фон стекла |
| `--on-glass` / `--on-glass-2` | #fffaf2 / 68 % | текст на стекле |

Правила: красный — только для срочного и ошибок; зелёный — только для главного действия и успеха;
золото — «ты здесь». Никаких «отладочных» цветов, чистого белого фона поверх сцены и серых кнопок
по умолчанию.

## 3. Шрифт и размеры

- **Nunito** (кириллица, локальный файл `src/ui/fonts/`) — весь интерфейс; **Caveat** — рукописные
  заметки книги рецептов и подзаголовки меню. Шрифты лежат в сборке: игра работает без интернета.
- Шкала: 12.5 (служебное, капс заголовков стекла) · 13–14 (вторичный текст) · 15 (кнопки) ·
  17 (текущая задача) · 28 (часы, заголовки диалогов) · 40–68 (название в меню).
- Минимум 12.5 px. Капсом — только короткие подписи-рубрики (не длиннее 4 слов).
- Цифры времени — `tabular-nums`, чтобы не дрожали.

## 4. Отступы, радиусы, тени

- Шаг 4 px: 4 · 8 · 12 · 16 · 24. Край экрана — 16 px.
- Радиусы: 10 (мелочь) · 16 (карточки внутри стекла, уведомления) · 24 (стекло и бумага) · pill (кнопки).
- Тени: `--shadow-1` для кнопок, `--shadow-2` для плавающих слоёв. Без двойных рамок.

## 5. Кнопки и состояния

| Вид | Класс | Когда |
|---|---|---|
| Главная | `primary` (зелёная) | одно главное действие на экране/доке |
| Срочная | `danger` (красная) | прогнать кота, убавить огонь |
| Совет | `gold` | «Понятно» в обучении |
| Обычная | — | на бумаге белая, на стекле полупрозрачная |
| Тихая | `ghost` | «Журнал», второстепенное |

Состояния: наведение — подъём на 1 px и чуть светлее; нажатие — вдавливание; выключено — 42 %
прозрачности и без подъёма, причина — в `title` и в строке отклика; фокус с клавиатуры — золотая
обводка 3 px. Одна главная кнопка на панель.

## 6. Раскладка кухни (1280×720 — минимум, 1440×900 — основной)

```
┌ задача (стекло) ─────────┐   ┌ часы + таймеры ┐        ┌ 📱 🔊 ⏸ ┐
│ 🥗 ДЕНЬ 1 ИЗ 7 · …  📖 ? │   │    01:23       │        └─────────┘
│ Нарезать 2 морковки      │   │ 🥔 0:42 🥚 гот.│        ┌ 🐱 ▬ 💰 ┐
│ ▬▬▬▬▬▬▬ (шаги рецепта)    │   └────────────────┘        └─────────┘
└──────────────────────────┘                            уведомления (стекло, справа)
 совет-обучение (крупный план — слева)
                       [ подсказка действия — пилюля над доком ]
            ┌ док станции: ←  [продукты-фишки]        [главная кнопка] ┐
            └ строка отклика: полоса аккуратности · текст              ┘
```

- **Задача**: блюдо, следующий шаг одной фразой, точки шагов рецепта (готово — зелёные, текущий —
  золотой пульс). Несколько блюд — фишки блюд. Пожелания гостей — одна строка.
- **Часы**: только время дня и активные таймеры (кастрюли, горячее, духовка, курьер).
- **Статус**: кот (полоска голода) и деньги — маленькие фишки, без отдельных карточек.
- **Метки станций в 3D**: только значок; подпись выезжает при наведении, срочности или «ты здесь».
- **Док станции**: круглая «←», фишки-продукты (значок + имя + ×2), одна главная кнопка справа,
  строка отклика ниже. Инструкции текстом в доке запрещены — для этого есть совет и подсказка.
- **Уведомления**: компактные, ≤ 3 одновременно, срочные — с красной кромкой и таймером.

## 7. Обучение и подсказки

- Совет (`#tip`) показывается один раз на тему, закрывается «Понятно», в крупном плане уходит в левую
  колонку и не закрывает продукт. Повтор — кнопка «?».
- Подсказка действия (`#hint`) — одна фраза о причине отказа («Нож пошёл наискосок…»), 2–3 с.
- В 3D: белая стрелка и пунктир показывают следующий разрез в первый день и когда игрок замешкался.

## 8. Телефон

Цельное устройство: рамка, «чёлка», строка статуса (время, сеть, заряд), новогодние обои, сетка
приложений с подписями, нижняя полоска «домой». Приложения открываются внутри экрана с анимацией
масштаба. Пять приложений: Пятёрочка Доставка, Андрей, Банк, Кулинарная книга, Таймеры.

## 9. Анимации

- 120 мс — отклик кнопки; 220 мс — появление панели/уведомления (сдвиг 16 px + прозрачность).
- Пульс — только для «сейчас»: текущий шаг, готовая кастрюля.
- `prefers-reduced-motion` отключает анимации. Режим «Экономно» убирает размытие стекла (`body.low-fx`).

## 10. Запрещено в обычном режиме

Панель разработчика (только `?dev`), ссылки на тестовые страницы, технические числа (FPS, вызовы),
английские подписи, тексты длиннее двух строк в доке, больше одной главной кнопки, всплывашки,
закрывающие продукт или руку с ножом.
