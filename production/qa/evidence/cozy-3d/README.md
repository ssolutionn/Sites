Рендеры реальных экспортированных GLB через Blender/Cycles, не отдельные иллюстрации.

- `girl_threequarter.png` — героиня в позе idle, по референсу `references/02_character_and_title.jpg`.
- `cat_threequarter.png` — рыжий кот, idle.
