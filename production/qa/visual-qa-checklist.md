# Чек-лист визуальной проверки в браузере

> Владелец: QA Lead. Обновлён: 2026-10-08. Процедура прогона — навык `.claude/skills/browser-visual-qa/`.
> Проверяем после каждой большой правки интерфейса, сцены или механик и перед каждой сборкой для владельца.
> Каждый пункт проверяется на **1280×720** и **1440×900**. Снимки — `production/qa/evidence/<день>_<экран>_<ширина>.png`.
> Пункт отмечается, только если есть снимок или строка `OK` в выводе e2e. «Вроде нормально» — не отметка.

## Как запустить

```bash
cd /home/user/Sites
npm test                                   # логика: node:test, должно быть 0 fail
npx vite build                             # обычная сборка (с брендом)
VITE_NEUTRAL=1 npx vite build              # нейтральная сборка для публичных ссылок
npx vite preview --port 4174 --strictPort &
PW=/opt/node-tools/node_modules/playwright/index.mjs OUT=production/qa/evidence \
  node scripts/campaign-e2e.mjs http://localhost:4174/ 1280 720 d1
PW=/opt/node-tools/node_modules/playwright/index.mjs OUT=production/qa/evidence \
  node scripts/campaign-e2e.mjs http://localhost:4174/ 1440 900 d1
PW=/opt/node-tools/node_modules/playwright/index.mjs node scripts/board-shots.mjs http://localhost:4174/
ps aux | grep "vite preview --port 4174"   # затем kill <pid> своего сервера
```

Прогон e2e по дню 1 занимает 10–15 минут на программном рендере (SwiftShader) — это нормально.

## Критерии готовности (решение владельца)

- [ ] Продукты не дублируются визуально: на доске лежит ровно `qty` копий продукта, в миске — только перенесённое, на полке/в холодильнике не висит второй такой же «живой» продукт рядом с доской.
- [ ] Нарезка не выглядит квадратной кнопкой: продукт объёмный (видны кожура и мякоть), нож идёт за мышью, после разреза кусочки разъезжаются.
- [ ] Перемешивание меняет состояние блюда: на снимке после 1,5 оборота миска выглядит иначе, чем до перемешивания, а после 4 оборотов — однородно.
- [ ] Телефон выглядит как цельное устройство: корпус, скругления, статус-бар, ни одна часть не обрезана краем окна.
- [ ] Героиня и кот не ощущаются заглушками: это модели из `heroine.glb`/`cat.glb` с анимацией, а не примитивы-капсулы; кот реагирует на «Прогнать».
- [ ] В обычном режиме (без `?dev`) нет технических панелей: нет `#dev`, FPS, счётчиков вызовов, отладочных подписей.
- [ ] Новичок понимает, что делать: на каждом экране видна одна главная задача, первый заход на доску показывает совет, ошибка объясняется словами.

## Общие для всех экранов

- [ ] В консоли за весь прогон нет `error` и `pageerror` (строка e2e «консоль без ошибок»).
- [ ] Ни один текст не обрезан многоточием там, где обрезка не задумана; кириллица без «квадратиков» (шрифты Nunito/Caveat загрузились).
- [ ] Ни одна панель не выходит за край окна: `getBoundingClientRect()` любого видимого `#panel`, `#phone`, `#recipe`, `#tip` лежит внутри окна.
- [ ] Две панели не перекрывают друг друга больше чем на 8 px (кроме модальной поверх затемнения).
- [ ] Кликабельные элементы не меньше 32×32 px, расстояние между соседними кнопками не меньше 6 px.
- [ ] Текст основной надписи не меньше 14 px на 1280×720.
- [ ] На нейтральной сборке нигде нет логотипа и слова «Пятёрочка» (меню, телефон, вывески, иконка вкладки).
- [ ] Ассеты видимы: героиня, кот, мебель, продукты отрисованы (на снимке нет пустого розового/чёрного места вместо модели), 404 по `models/*.glb` в сети нет.

## Главное меню

- [ ] Название игры читается целиком, не перекрыто кнопками.
- [ ] Кнопка «Новая кампания» (или «Продолжить») — самая заметная, видна без прокрутки на обоих разрешениях.
- [ ] Строка «от «Пятёрочки»» есть в обычной сборке и отсутствует в нейтральной.
- [ ] Переключатели «Звук» и «Качество» меняют подпись сразу после нажатия.
- [ ] Без `?dev` в углу нет блока DEV (строка e2e «без ?dev нет технических панелей»).

## Карточка дня (интро)

- [ ] Видно: номер дня, блюдо(а) дня, ориентир по времени, кнопка входа на кухню.
- [ ] Кнопка входа не перекрывает текст задания, текст не уходит под край на 1280×720.
- [ ] Кнопка «Esc»/«Назад» возвращает в меню без потери сохранения.

## Кухня — HUD

- [ ] Сверху видна текущая задача одной строкой и игровые часы; в обзоре кухни HUD занимает не больше 15 % площади экрана.
- [ ] HUD не перекрывает героиню ни в одной точке её маршрута между станциями.
- [ ] Подписи станций (Плита, Доска, Раковина, Миска, Телефон…) не налезают друг на друга и на HUD.
- [ ] Значок непрочитанного на кнопке телефона появляется при новом сообщении и гаснет после открытия.
- [ ] Клик по полу ведёт героиню без открытия панели; путь обходит остров.
- [ ] Кнопка «Завершить день» скрыта, пока не все блюда готовы, и видна после.

## Плита

- [ ] Обе конфорки видны, на каждой своя кастрюля с подписью продукта и обратным отсчётом.
- [ ] Кипение заметно глазом: пар/пузыри, к концу варки — сильнее.
- [ ] Убегающая вода показана тревожно (цвет/пена) и кнопкой «Убавить огонь», кнопка не закрывает кастрюлю.
- [ ] После «Достать» горячий продукт помечен как горячий, на доске он не режется — подсказка про раковину.

## Доска

- [ ] На 1280×720 ни одна панель не перекрывает продукт на доске больше чем на 10 % (строка e2e «интерфейс закрывает ≤ 10 % продукта» для каждого продукта).
- [ ] Совет при первом заходе стоит сбоку и не закрывает продукт (≤ 10 %), закрывается кнопкой «Понятно».
- [ ] Продукт × 2 лежит двумя копиями рядом, с зазором, обе целиком в кадре.
- [ ] Морковь, огурец, колбаса, яйцо, картофель узнаются по форме и цвету без подписи.
- [ ] Пока кнопка зажата, нож в руке идёт за курсором, виден пунктир будущего разреза.
- [ ] Росчерк сверху вниз даёт полоски, слева направо — кубики; на снимке `d1_board_<продукт>_cubes` кубики примерно одного размера.
- [ ] Мимо продукта, наискосок, клик без движения — разреза нет, подсказка словами, следующий правильный росчерк режет.
- [ ] Курсор над доской — «прицел», а не стрелка.
- [ ] «В миску» до первого разреза — отказ с подсказкой «Сначала сделай хотя бы один разрез».

## Раковина

- [ ] Кнопка «Остудить» есть только для горячего продукта и пропадает после остужения.
- [ ] Мытьё: губка идёт за мышью, грязь стирается там, где провели, процент чистоты растёт.
- [ ] Вода видна (струя/блики), раковина не перекрыта панелью больше чем на 10 %.

## Миска

- [ ] Каждый перенесённый с доски продукт виден в миске своим цветом.
- [ ] Горошек и майонез появляются в миске сразу после добавления.
- [ ] Соль/перец/проба: результат пробы виден словами («в самый раз!», «пресно»).
- [ ] Неподвижное удержание кнопки не перемешивает (строка e2e).
- [ ] После 1,5 оборота вид миски изменился (снимок `d1_bowl_mixing`), после 4 оборотов блюдо готово.
- [ ] Ложка идёт за курсором по кругу и не уходит за край миски.

## Телефон — домашний экран

- [ ] Телефон целиком в кадре на обоих разрешениях (строка e2e «телефон целиком в кадре»).
- [ ] Видны обои, часы, иконки пяти приложений с подписями: Пятёрочка доставка, Андрей, Банк и бонусы, Кулинарная книга, Таймеры кухни.
- [ ] Иконки не налезают друг на друга, подписи не обрезаны.
- [ ] Закрыть телефон можно кнопкой и клавишей Esc; игра после этого не на паузе.

### Пятёрочка доставка (в нейтральной сборке — без бренда)

- [ ] Каталог прокручивается, недоступные товары серые, цена видна у каждого товара.
- [ ] «+»/«−» меняют количество, итог и бюджет пересчитываются сразу.
- [ ] Статус заказа виден полосой этапов; «Забрать заказ» появляется только по прибытии.

### Андрей

- [ ] Чат читается сверху вниз, новое сообщение внизу, фото в ленте не растянуто.
- [ ] Новое сообщение во время готовки даёт значок на иконке и не открывает телефон само.

### Банк и бонусы

- [ ] Видны бюджет дня, потрачено, бонусы; числа совпадают с тем, что показывает доставка.
- [ ] Обмен бонусов недоступен при нехватке баллов — кнопка серая с подсказкой.

### Кулинарная книга

- [ ] Рецепт дня с шагами и граммовками; отмеченные шаги совпадают с выполненными.
- [ ] Текст не мельче 14 px, длинный рецепт прокручивается внутри экрана телефона.

### Таймеры кухни

- [ ] Таймер каждой кастрюли совпадает с отсчётом на плите (расхождение ≤ 1 с).
- [ ] Сработавший таймер заметен (цвет/звук) и сбрасывается после «Достать».

## Книга рецептов (клавиша Q)

- [ ] Открывается и закрывается по Q и по ×; не перекрывает доску/миску в крупном плане больше чем на 10 %.
- [ ] Выполненные шаги отмечены, текущий шаг выделен.

## Итог дня

- [ ] Видны оценка блюда, порядок, темп, звёзды; числа не обрезаны.
- [ ] Кнопки «Следующий день» и «В меню» видны без прокрутки на 1280×720.
- [ ] После перезагрузки страницы день 1 отмечен пройденным, день 2 открыт.

## Пауза

- [ ] Esc в кухне ставит паузу: таймеры стоят (часы HUD не меняются 3 с), сцена затемнена.
- [ ] Повторный Esc или «Продолжить» возвращает в кухню без потери состояния.
- [ ] Из паузы доступны звук, качество, выход в меню.

## Ошибки игрока и устойчивость

- [ ] После серии неверных действий (мимо, наискосок, перенос до разреза, горячее на доску) следующее верное действие срабатывает — игра не «залипает».
- [ ] Отпускание кнопки мыши за пределами окна не оставляет нож/ложку «зажатыми».
- [ ] Потеря фокуса окна ставит паузу; возврат — продолжение без ошибок в консоли.
- [ ] Кот утащил кусок — появляется «Взять замену», после замены продукт можно дорезать и перенести.
