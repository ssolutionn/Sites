# Галерея для владельца

Скачайте `3d-preview.html` кнопкой **Download raw file** в GitHub и откройте в браузере.
Это один файл: в нём 27 моделей, текстуры и Three.js; интернет, npm и сервер не нужны.
Модели вращаются мышью, масштаб меняется колесом; для персонажей можно выбрать клип.
Кнопка «Скачать GLB» выгружает выбранную модель отдельно.

Это предварительная 3D-версия для оценки внешнего вида и поз, не сборка всей игры.
Проверено: все 27 моделей загружаются из встроенных данных; idle/walk и выбор кота работают;
запросов к внешним серверам и ошибок консоли нет. Навигация file:// в облачном Chromium
запрещена политикой среды, поэтому проверка выполнена через загрузку содержимого HTML в страницу.

Воспроизведение: `npm run models:sync`, затем `npm run models:preview`.
Исходники — `assets/`, воспроизводимые генераторы — `scripts/art/`.
Игра использует 12 моделей; все 27 доступны здесь для оценки и скачивания.
