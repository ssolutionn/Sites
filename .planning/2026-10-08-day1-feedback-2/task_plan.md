# Task Plan: День 1 — второй круг правок владельца (0.7)

## Goal
Нарезка как в жизни: нож режет по реальному следу мыши (дрогнула рука — кривой кусок), мелкий кубик оливье
рубкой ритмом, доска крутится на A/D (тап — 90°, удержание — свободно). Крутилки у конфорок и у радио
(своя музыка кодом), остудить под краном руками, понятные соль/перец, никакой «воды» в оливье,
живая лента Андрея. Баги: две кастрюли в одном месте, «пустые» куски продуктов.

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Мелкий кубик — рубкой ритмом (владелец) | 10–15 разрезов на продукт без занудства; шаг = сдвиг руки |
| Доска: оба способа, только A/D (владелец) | тап — 90° плавно, удержание — свободно |
| Радио: музыка кодом (владелец) | общественное достояние, без вопросов с правами для Steam |
| «Вода» = кнопка «Разбавить 💧» в миске (владелец не понял) | воду в оливье не льют; пересол спасают картошкой/яйцом |
| Остудить под краном — руками (владелец) | видно струю и пар |
| Лента Андрея — живая (владелец) | ИДЕАЛЬНОЕ оливье дочери маминой подруги, мемы с котиками |
| Нарезка по растровой маске | кривой, наклонный и волнистый разрез, свободный угол доски и рубка — одной моделью |
