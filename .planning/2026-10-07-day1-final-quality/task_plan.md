## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Жесты — чистая логика в gestures.js | тестируемо node:test без DOM |
| R остаётся необязательным | поворот доски не мешает, но не нужен |
| Брендированные ссылки не публикуем | только VITE_NEUTRAL=1 |
| Логический контур моркови не меняем | тонкий конус ломает оценку кубиков; узнаваемость — шейдером |
| Документы и навыки пишут агенты параллельно | art-bible/asset-contract (art-director), interaction-spec/lessons.js (game-designer), visual-qa/skills (qa-lead) |
| ui-guidelines пишу сам | это дизайн-система, которую сразу внедряю |
| Порядок вкуса: соль → мешать → проба (владелец) | соль не распределена — проба обманчива; досолила после — ещё оборот |
| Огурцы делим: pickle / cucumber (владелец) | оливье — солёные, крабовый и канапе — свежие |
| Чистка картофеля и яиц — отдельный шаг на доске (владелец) | маска покрытия, как намазывание; горячее не чистится |
| Чистка не зависит от скорости мыши | нож — инструмент, а не порция: каждый шаг снимает одинаково; на 60 FPS и на 3 FPS результат один |
